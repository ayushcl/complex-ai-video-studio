# Local Project Management Lite

At session start, read `_project-tracker/TRACKER.md`, then treat `_project-tracker/CURRENT_STATE.md` as the current project truth.

Read `_project-tracker/NEXT_HANDOVER.md` only when the user asks for direct continuation or resume of prior work.

Codex-native skills live in `.agents/skills/`; use them when their descriptions match the task.

When installed over an existing project, this content is merged/appended. It never blind-replaces existing project governance.
